# 2026 중학생을 위한 고교학점제 박람회 안내 웹사이트

강원특별자치도교육청 주최 「2026 중학생을 위한 고교학점제 박람회」 안내 웹사이트입니다.
서버가 필요 없는 순수 정적 사이트(HTML/CSS/JS)로, GitHub Pages 등 어디에나 올릴 수 있습니다.

## 구성

| 파일/폴더 | 설명 |
|---|---|
| `index.html` | 메인 페이지 (행사 개요, 권역 카드, 프로그램, 참가 신청, 생기부 안내, 갤러리, 문의) |
| `region.html` | 권역별 페이지 — `region.html?region=sokcho / chuncheon / gangneung / wonju` |
| `admin.html` | 관리자 페이지 (자료 등록·수정) |
| `data/site-data.js` | **사이트의 모든 내용이 담긴 데이터 파일** (일정·장소·학교·링크·연락처) |
| `assets/schools/` | 학교소개자료 파일 (PDF/HWPX) |
| `assets/photos/` | 2025년 박람회 사진 |

## GitHub Pages 배포 방법

1. GitHub에 새 저장소를 만들고 이 `website` 폴더의 **내용물 전체**를 저장소 루트에 업로드(커밋)합니다.
2. 저장소 → Settings → Pages → Branch를 `main`(root)으로 선택 후 저장합니다.
3. 잠시 후 `https://<계정명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.

## 관리자 사용 방법

1. 사이트 하단의 "관리자" 링크 또는 `admin.html`로 접속합니다. (초기 비밀번호: `gwedu2026` — 접속 후 변경 권장)
2. 신청 링크, 권역 일시·장소, 운영 사무소 전화번호, 공지, 학교 목록을 수정합니다.
3. **[미리보기 저장]** — 지금 쓰는 브라우저에서만 적용해 확인합니다.
4. **[배포용 파일 내보내기]** — `site-data.js`를 내려받아, GitHub 저장소의 `data/site-data.js`를 이 파일로 교체(커밋)하면 모든 방문자에게 반영됩니다.
   - 웹에서 간단히: GitHub 저장소 → `data` 폴더 → `site-data.js` → 연필(Edit) 아이콘 대신 **Upload files**로 같은 이름의 파일을 올리면 덮어쓰기 됩니다.

### 학교소개자료 교체/추가

1. 저장소의 `assets/schools/` 폴더에 새 PDF/HWPX 파일을 업로드합니다.
2. 관리자 페이지의 학교 목록에서 "자료 파일" 칸에 업로드한 파일 이름(예: `속초고등학교_소개자료.pdf`)을 입력합니다.
   - 외부 주소로 연결하려면 `https://…` 형태의 URL을 입력하면 됩니다.
   - 자료가 2개인 학교는 쉼표(,)로 구분해 입력합니다.
3. 내보낸 `site-data.js`를 저장소에 반영합니다.

> ⚠️ 관리자 비밀번호는 정적 사이트 특성상 간이 잠금 장치입니다(코드에 포함됨).
> 실제 데이터 변경 권한은 GitHub 저장소 권한으로 관리되므로, 저장소 공동 작업자를 신뢰할 수 있는 담당자로만 유지하세요.

## 신청 버튼 링크 연결

특강/상담 신청 폼(예: 네이버폼, 구글폼)이 준비되면 관리자 페이지의 "참가 신청 링크"에 주소를 입력하세요.
비워 두면 버튼이 "신청 오픈 예정"으로 표시됩니다. 권역별로 다른 폼을 쓰는 경우 권역별 칸에 입력하면 해당 권역 페이지에서 우선 적용됩니다.

## 로컬에서 확인

`index.html`을 더블클릭해 브라우저로 열면 바로 동작합니다(별도 서버 불필요).
